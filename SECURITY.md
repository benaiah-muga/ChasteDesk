# Security policy

ChasteDesk handles customer conversations and provider credentials. Please report suspected vulnerabilities privately.

Use a [GitHub security advisory](https://github.com/benaiah-muga/ChasteDesk/security/advisories/new) on this repository. Do not open a public issue with exploit details.

Include:

- Affected version or commit
- A description of the issue
- Steps to reproduce
- Impact and any known mitigations

The full threat model, controls, and operator hardening checklist are in [docs/SECURITY.md](docs/SECURITY.md).

This is an M1 preview. Security fixes are best effort, but reports are taken seriously.
